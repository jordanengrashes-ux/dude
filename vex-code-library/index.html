Lesson 1Software & Code Structure

Libraries and how to read a line

Spot the library by its prefix

The word before :: tells you which library the line belongs to. There is no LemLib in this project, and there is no chassis object to build.

ctnav::driveDistance(24);       // CT Nav  — moving
ctd::Console.println("go");     // CT Dash — the log
ctguard::preflight();           // CT Guard — hardware check
pros::delay(20);                // PROS    — the system underneath

Library, action, value

Read it out loud as "CT Nav, turn to heading, ninety." The number is the part you usually change.

ctnav::turnToHeading(90);
// library  ::  action  ( value )

The opcontrol loop

src/main.cpp · inside opcontrol()

Push test

Expected reading for 3.25 in wheels

wheel circumference = π × 3.25 in            = 10.21 in
turns for 24 in     = 24 ÷ 10.21             = 2.35 turns
degrees             = 2.35 × 360             = 846 degrees

Split-stick tuning

Stage 1 · Deadband

include/robot_config.hpp

Treats a nearly-centred stick as centred so a worn controller cannot creep the robot across the field.

constexpr float DRIVE_DEADBAND = 0.04F;   // about 5 counts of the controller's 127

Stage 2 · Curves

include/robot_config.hpp

Output is stickcurve, so half stick gives less than half power. The turn curve is gentler because the mix already scales turning by throttle.

constexpr float DRIVE_THROTTLE_CURVE = 3.0F;
constexpr float DRIVE_TURN_CURVE     = 2.0F;

Stage 3 · Low-speed steering cap

include/robot_config.hpp

Below 30% throttle, steering authority stays flat at 0.30.

constexpr float DRIVE_STEER_FLOOR = 0.30F;   // the MOST steering you get at low speed

// authority = max(|throttle|, DRIVE_STEER_FLOOR)

Lesson 2Field Coordinates & Moving to a Spot

The field grid

Set the starting pose

"I am standing here, facing zero." Every move after this is measured from here.

ctnav::setPose(0, 0, 0);

Read the position back

Prints where the robot thinks it is.

const ctnav::Pose p = ctnav::pose();
ctd::Console.println("x %.1f  y %.1f  h %.1f", p.x, p.y, p.theta);

The four simple moves

Drive a distance

ctnav::driveDistance(24);    // forward 24 inches
ctnav::driveDistance(-12);   // backwards 12 inches

Turn by an angle

Turns on the spot, relative to the current heading.

ctnav::turnAngle(90);    // 90 degrees to the RIGHT, from wherever it is pointing now
ctnav::turnAngle(-45);   // 45 degrees to the left

Turn to a heading

Turns to an absolute compass heading the shorter way.

ctnav::turnToHeading(90);   // end up facing 90, whichever way is shorter

Turn to face a point

Works out the heading to a coordinate for you. Compass bearing is atan2(dx, dy), not the textbook atan2(dy, dx), so let this call do it.

ctnav::turnToPoint(48, 24);        // point the front at that spot
ctnav::turnAwayFromPoint(48, 24);  // point the BACK at it, ready to reverse in

Point and pose

Go to a place

Drives to that spot, steering to hold the line.

ctnav::moveToPoint(24, 24);

Go to a place and face a direction

Drives a curve that ends at the spot facing 90°.

ctnav::moveToPose(24, 24, 90);

Plan a move without driving it

Checks whether the move is possible and how long it takes, and prints why not if it can't.

const ctnav::MovePlan plan = ctnav::planMoveToPose(24, 24, 90);
ctd::Console.println("ok %d  %.0f in  %.1f s", plan.feasible, plan.length, plan.duration);
if (!plan.feasible) ctd::Console.println("no: %s", plan.refusal);

Starting up right

initialize() in order

src/main.cpp

Builds the menu, calibrates, checks the hardware, and says it is ready. Keep the robot completely still for about two seconds while ctnav::start() runs.

void initialize() {
    auton::start();                 // 1. build the menu FIRST
    ctd::Dash.start();              // 2. draw it, so buttons show while the IMU settles

    left_motors.set_brake_mode_all(pros::MotorBrake::brake);
    right_motors.set_brake_mode_all(pros::MotorBrake::brake);   // 3. how the drive stops

    ctnav::start({ /* motors, imu, limits, gains, geometry */ });  // 4. calibrate + track

    ctguard::watch(left_motors,  "drive left",  "ctnav", config::DRIVE_GEARSET);
    ctguard::watch(right_motors, "drive right", "ctnav", config::DRIVE_GEARSET);
    ctguard::watchDevice(config::IMU_PORT, "inertial", pros::DeviceType::imu);
    ctguard::preflight();           // 5. check it all, once, out loud
    ctguard::start();               // 6. keep checking, in the background

    Brain.Screen.toast("Ready");
}

Lesson 4Tasks, Health & Logging

Doing two things at once

A loop that shares the brain

Runs about 50 times a second and gives the screen and hardware-watch tasks a turn.

while (true) {
    driver::drive();
    input::update();
    pros::delay(20);   // let every other task have a turn
}

Overlap a mechanism with a drive

Starts the drive, runs the intake alongside it, then waits and asks how the drive ended. The starter has no intake motor, so swap in your own mechanism. Always check the result from waitUntilDone().

ctnav::launch(ctnav::Move::driveDistance(48));   // returns immediately

intake.move(127);                                // happens while the robot drives
pros::delay(300);
intake.move(0);

const ctnav::MoveResult how = ctnav::waitUntilDone();

Your own background task

Starts a second loop that runs alongside everything else, forever.

pros::Task lift_task([] {
    while (true) {
        // read a sensor, decide, command the lift motor
        pros::delay(20);
    }
}, "lift");

One motor, one owner

Records who owns each motor group.

ctguard::watch(left_motors, "drive left", "ctnav", config::DRIVE_GEARSET);
ctguard::watch(lift_motors, "lift",       "lift",  pros::MotorGears::red);

Health monitoring

Register hardware with CT Guard

src/main.cpp · inside initialize()

Registers the drive and the inertial.

ctguard::watch(right_motors, "drive right", "ctnav", config::DRIVE_GEARSET);

Health thresholds

Sets what counts as wrong. Remember 25%: below it the brain cuts motor power and moves report STALLED, just like hitting a wall.

battery_fault_pct = 25;     // where a V5 starts cutting motor power under load
battery_warn_pct  = 60;     // below this, a constant measured now will not hold on a full pack
motor_warn_c      = 55.0;   // where V5 motors begin folding back power, silently
motor_warn_ma     = 2200;   // near the stall current

Keep watching in the background

Starts one background task that keeps checking through autonomous and driving.

ctguard::start();

Refuse to drive a broken robot

src/main.cpp

Skips the routine if any fault is outstanding.

void autonomous() {
    if (!ctguard::requireHealthy()) {
        return;   // it has already said what is wrong
    }
    auton::run();
}

Heartbeat

Prints uptime and battery every HEARTBEAT_MS. static keeps last_beat from resetting each loop.

static unsigned long last_beat = 0;
if (pros::millis() - last_beat >= config::HEARTBEAT_MS) {
    last_beat = pros::millis();
    ctd::Console.println("alive %lus  batt %d%%", pros::millis() / 1000,
                         static_cast<int>(pros::battery::get_capacity()));
}
